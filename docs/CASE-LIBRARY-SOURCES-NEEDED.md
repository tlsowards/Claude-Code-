# Case library: 22 cases that need a source

Prepared November 18, 2026 for Dr. Sowards. These cases are taught in the instructor courses and belong in the Case library, but no copy of the court's opinion could be reached from the build environment, so no brief has been written. Every library brief is written from the opinion itself, never from a summary, so each of these needs one of the following: a PDF of the opinion, a link to a public copy, or a free CourtListener account key (entered through the secure form, never pasted in chat) so the opinions can be pulled directly.

What was tried: the Library of Congress U.S. Reports archive (Supreme Court only), the Public.Resource.Org Federal Reporter archive (F.2d and F.3d to about volume 491; no F. Supp.), the Ninth Circuit's own opinion archive (gaps in 2007 to 2008 and some later files), and govinfo. CourtListener, Justia, and FindLaw refused automated access.

Columns: W24 = 24-hour ACI update, W80 = 80-hour ACI, W40 = 40-hour ACI, IWI = Impact Weapons Instructor. The citation is as it appears in the course materials; a few are marked where the course cite itself needs checking.

## How to hand them over

Any of these works: PDFs in a Dropbox folder named for the purpose (for example "/Sowards Consulting App/Opinions for the Case library"), links to a public copy, or a free CourtListener account key supplied through the secure credential form. Once a source arrives, each brief follows the same process as the other 65: read in full, written to the standard, validated, and sent up in a draft pull request for "merge".
